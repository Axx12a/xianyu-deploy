# 网络与手机访问

## 前提：电脑必须开着

服务跑在本机，所以不管用哪种方案，**电脑必须开机且 Docker Desktop 在运行**。

```
电脑开机 → Docker Desktop 运行 → 6 个容器在跑
```

---

## 在家（同一 WiFi）

手机浏览器直接打开局域网地址即可：

```
http://<电脑的局域网IP>:9000
```

查电脑局域网 IP：

```powershell
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' }
```

## 在外面

需要一条从手机到家里电脑的通路。下面按推荐度排序。

### 方案一：Tailscale / ZeroTier（推荐）

**原理**：把设备拉进一个私有虚拟局域网，服务不暴露到公网。

**优点**：外人探测不到服务的存在；端到端加密；个人版免费。

**步骤**：

1. 电脑装 Tailscale 并登录
2. 手机装 Tailscale，**登录同一个账号**
3. 查电脑地址：
   ```bash
   tailscale ip -4        # 形如 100.126.44.32
   ```
4. 手机浏览器打开 `http://100.126.44.32:9000`

**验证**：手机关掉 WiFi 用流量打开，能通才算真正配好。

**注意**：国内访问 Tailscale 的控制服务器（登录那一步）有时不稳。
连上之后数据传输是直连的，通常没问题。

**可以顺手做的加固**：Tailscale 通了之后，把 Windows 防火墙打开
（原本可能是关闭的），这样局域网里其他设备就看不到你的 9000 端口了。
打开防火墙后如果手机连不上，需要放行 Tailscale 的虚拟网卡。

### 方案二：远程桌面

**原理**：手机远程操作家里电脑的桌面。

**优点**：零配置，不碰 Docker 不碰隧道；不开放任何端口。

**缺点**：手机操作电脑界面体验一般。

适合"偶尔看一眼、回一句"的场景。ToDesk、向日葵都有免费版。

### 方案三：Cloudflare Tunnel

**原理**：在电脑上跑 `cloudflared` 主动连出去，Cloudflare 把一个域名
指向你家里的服务。

**优点**：手机不用装客户端，浏览器直接开。

**缺点与风险**：

- **服务暴露到公网**，任何人都能打开那个网址（可加 Cloudflare Access 验证）
- 需要一个域名（隧道和 Access 免费，域名要买，一年几十）
- 国内访问免费版节点（都在境外）速度一般

**如果要用，必须做**：

1. 配上 Cloudflare Access，用邮箱验证码拦住未授权访问
2. **先把后台默认密码 `admin123` 改掉**
3. 强密码 + 不对外分享网址

### 方案四：frp + 云服务器

**原理**：自己买一台国内云服务器做中转。

**优点**：国内速度最好，完全可控。

**缺点**：有成本（一年几十到一两百）。

### 不推荐：家宽端口映射

国内运营商大多对家宽做 CGNAT 或封禁入站端口，申请公网 IP 不一定办得下来。
即使办下来，把存着全部账号凭据的后台直接暴露到公网，风险最高。

---

## 方案对比

| 方案 | 手机要装客户端 | 服务是否暴露公网 | 需要域名 | 国内速度 | 成本 |
|---|---|---|---|---|---|
| Tailscale | 要 | **否** | 否 | 直连好，中继慢 | 免费 |
| 远程桌面 | 要 | 否 | 否 | 好 | 免费 |
| Cloudflare Tunnel | 不要 | **是** | 是 | 一般 | 域名费 |
| frp | 不要 | 半暴露（自己的服务器） | 可选 | 最好 | 服务器费 |

## 安全提醒

这台机器上存着：

- 全部闲鱼账号的 **Cookie**（等同于账号访问权限）
- **账号密码**（MySQL 中明文存储）
- 买家订单与联系信息

所以：

- **不要把 9000 端口直接开放到公网**
- 不要在没有访问控制的情况下用 Cloudflare Tunnel 之类的方案
- 后台密码不要用默认的 `admin123`
- `xianyu_auto_reply/` 里的数据、日志、备份不要外传
